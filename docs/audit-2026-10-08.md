## Perbaikan per temuan (2026-10-08, branch `fix/audit-2026-10`)

- **F01**: `start-backend.js` memakai `HOST` (default `127.0.0.1`) dan log menulis alamat sebenarnya. Compose mem-publish `127.0.0.1:8000:8000`.
- **F02, F08, F20**: helper bersama `is_safe_media_path()` dan `media_ref_basename()` di `video_engine.py` (decode dulu, baru basename). Dipakai di `download_service`, `download_clip_segment`, `extract_clip_frame`, `media.py`, dan `analyze.py`. `glob` diganti pencocokan substring. Setiap perintah yt-dlp mendapat `--` sebelum URL; `extract_clip_frame` hanya meneruskan URL `http(s)://`. Catatan: helper dipanggil di tiap jalur (6 lokasi) karena logika pencarian file di tiap jalur berbeda; menyatukannya jadi satu resolver = refactor terpisah.
- **F04**: `TrustedHostMiddleware` (`ALLOWED_HOSTS`, default `localhost,127.0.0.1`) + middleware yang menolak POST/PUT/DELETE dengan `Origin` asing (403). Berlaku untuk semua endpoint sekaligus.
- **F05**: `field_validator` di `RenderSettingsModel` membuang path di luar `UPLOADS_DIR`.
- **F06**: cookies hanya ditulis ke `backend/cookies.txt` dengan mode `0600`; salinan lama di root dihapus saat simpan.
- **F07**: catch-all memakai `resolve()` + `is_relative_to(dist_dir)`; `/api/*` yang tidak dikenal kini 404 JSON.
- **F09/F10/F17 (Docker)**: healthcheck ke `/api/health`; volume ke `backend/temp_clips`, `backend/exports`, `backend/fonts`; user non-root `app` (uid 1000); install `fonts-noto-color-emoji`.
- **F11**: update menjadi `def` (jalan di threadpool); restart menolak dengan 501 bila npm tidak ada; runner hanya mematikan proses yang cwd-nya root aplikasi (Linux/macOS via `lsof`) atau bernama node/python (Windows). Port backend kini dari `BACKEND_PORT`.
- **F12**: fase gagal disimpan sebelum status diubah ke `error`.
- **F13**: `backend/utils/jobs.py` menyimpan maksimal 50 job selesai per registry; job yang berjalan tidak disentuh.
- **F14**: label jujur "Waiting for Gemini" + detik berlalu.
- **F15**: `backend/tests/test_audit_fixes.py` (10 test, `unittest` + `TestClient`) dan `.github/workflows/ci.yml` (build frontend + test backend).
- **F16**: `normalize_source_url()` di `utils/text.py`; `requirements.txt` root dihapus (Dockerfile memakai `backend/requirements.txt`); `backend/haarcascade_frontalface_default.xml` + `CASCADE_PATH` dihapus.
- **F17**: batas atas major version di `backend/requirements.txt`, kecuali `yt-dlp` (harus selalu terbaru).
- **F18**: `seguiemj.ttf` dihapus, diganti `NotoColorEmoji.ttf` (OFL 1.1, sumber `googlefonts/noto-emoji` `2D/fonts/`, sha256 `15671215…cc44`, lisensi di `backend/fonts/NotoColorEmoji-OFL.txt`). Pillow 12.3 hanya bisa memuat font bitmap ini di 109 px, jadi `render_emoji_image()` merender di ukuran strike lalu menskalakan. Font yang dimuat tapi tidak tergambar (COLRv1 bawaan Fedora, Twemoji Mozilla) dilewati otomatis.
- **F19**: key dikirim lewat header `X-Gemini-Api-Key`.
- **F03** (keputusan user 2026-10-08: sambungkan ke UI): `backend/utils/auth.py` jadi satu aturan untuk middleware global dan `verify_admin_access`. Bila `CHEAT_CLIP_API_KEY`/`ADMIN_API_KEY` diisi, semua `/api/*`, `/docs`, `/openapi.json` butuh key (kecuali `/api/health`, `/api/auth/status`, `/api/auth/session`). Script mengirim `X-API-Key`/Bearer; UI (`src/components/AccessKeyGate.tsx`) menukar key sekali dengan cookie `HttpOnly; SameSite=Strict` berisi HMAC turunan key (bukan key mentah), berlaku 30 hari, sehingga `<video>`, `<img>`, link download, dan EventSource ikut terautentikasi. Default tetap mati (bind loopback). Batasan: kalau cookie kedaluwarsa di tengah sesi, request gagal 401 sampai halaman di-reload.

- **F28**: `yt-dlp[default]>=2026.0.0` (menarik `yt-dlp-ejs==0.8.0`, brotli, certifi, mutagen, pycryptodomex, websockets).
- **F27**: `.dockerignore` mengecualikan `**/.env*` (kecuali template), `**/cookies.txt`, `backend/temp_clips`, `backend/exports`.
